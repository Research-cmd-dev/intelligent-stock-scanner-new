# Grok Outputs

This folder contains long or important outputs from Grok, saved as files so they can be easily opened and copied in the VS Code editor (bypassing terminal clipboard issues in Codespaces).

## How to Use

Just ask Grok things like:

- "Save this to a file"
- "Write the full review to `repo-review.md`"
- "Save this analysis in `grok-outputs/backtest-results.md`"
- "Put the output in a file"

Grok will write properly formatted Markdown files here.

## Recommended Naming

- Use descriptive names: `repo-review-2026-05-20.md`
- Or topic-based: `narrative-layer-analysis.md`
- Date-based when doing repeated work
